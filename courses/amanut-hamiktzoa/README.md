# אמנות המקצוע — המפיק בתעשיית המוזיקה

קורס השלמה למפיקים מוזיקליים. מכסה את **עולמות 2–4** של מפת הידע למפיק
(תעשייה, עסק, קריירה) — כל מה שאינו הפקה מוזיקלית עצמה.

## למה הקורס הזה נוצר — ממצאי הבדיקה

נבדק הקורס הקיים בריפו (`יסודות המוזיקה המקיף`, 7 כרכים, ~3.6MB,
`git show 517e77a5`). ספירת מונחים בקובץ המלא:

| מונח | מופעים | הערה |
|---|---|---|
| זכויות יוצרים | 2 | שניהם בתוך פרק סמפלים, כאזהרה |
| חוזה | 1 | לא בהקשר משפטי (`LUFS חוזה איך זה ירגיש`) |
| מאסטר | 96 | כולם במובן mastering, לא master recording |
| Sync | 23 | כולם במובן סנכרון אודיו |
| הפצה | 6 | כולם בהקשר טכני של מאסטרינג |
| ISRC | 1 | אזכור אגב בפרק DDPi |
| Split · תמלוג · לייבל · קרדיט · תמחור · חשבונית · נטוורקינג · A&R · Recoupment · Sample Clearance · Publishing · עורך דין | **0** | — |

מסקנה: הקורס הקיים הוא כמעט ב-100% עולם 1 (מוזיקה והפקה). עולמות 2–4
נעדרים כמעט לחלוטין. הפער מצדיק קורס נפרד ולא הוספת פרקים.

3 עולמות · 7 כרכים · 29 פרקים · ~23,000 מילים

| כרך | עולם | נושא | פרקים |
|---|---|---|---|
| א | 2 | האמן ואנשי המקצוע | 1–5 |
| ב | 2 | זכויות וקרדיטים | 6–10 |
| ג | 2 | חוזים וכסף מהמוזיקה | 11–12 |
| ד | 2 | לייבלים, הפצה וסינכרון | 13–15 |

ההפרדה בין העולמות נשמרת בממשק — דף הבית מקבץ את הכרכים תחת כותרת עולם,
ופרק 29 מחזיר אותה כמסגרת אבחון עצמי.

## בנייה

```bash
python3 build.py     # src/ → dist/אמנות-המקצוע.html
```

קובץ HTML יחיד, ללא תלויות חיצוניות פרט לגופני Google (עם נפילה חיננית
לגופני מערכת). `build.py` מתריע על פרק שהוכרז ב-`structure.json` ואין לו
קובץ תוכן.

```
src/
├─ shell.html       מעטפת ה-SPA: CSS + מנוע הניווט
├─ structure.json   עולמות, כרכים, פרקים
├─ tools.js         הכלים האינטראקטיביים
└─ chapters/        ch01.html … ch29.html — תוכן הפרקים
```

## עיצוב

תואם את מערכת העיצוב של הקורס הקיים: RTL, פלטת ירוק־יער/זהב עתיק
(`--bg:#0a1813`, `--gold:#b8893f`), גופני Assistant/Heebo, ואותה אוצר מילים
של רכיבים — `.box-gold/blue/green/red`, `.mini-sum`, `.sec`, `.chap-item`,
`.reader-hero`, מד התקדמות ו-localStorage לסימון פרקים שנקראו.
