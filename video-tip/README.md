# תפסיקו להתלונן. תתחילו לנגן!

סרטון טיפ למוזיקאים (41 שניות, 1080×1920, 60 פריימים בשנייה) שנבנה כולו בקוד:
האנימציה היא דף HTML שמונע על ידי GSAP, והפסקול מסונתז מאפס ב־Node (גיטרה, תופים, בס ואפקטים).

הקובץ המוכן: `tip-video.mp4`. תמונת שער: `cover.jpg`. לוח סצנות: `storyboard.jpg`.

`HANDOFF.md` הוא מסמך העברה עצמאי: מפרט מלא של הסרטון וכל קוד המקור בקובץ אחד, כדי שצ'אט אחר יוכל לשחזר אותו אחד לאחד.

## מה יש כאן

| קובץ | תפקיד |
| --- | --- |
| `src/timing.js` | ציר הזמן המשותף: מתי כל סצנה מתחילה, וכל פריטה, תוף ואפקט. גם התמונה וגם הסאונד קוראים ממנו, ולכן הם תמיד מסונכרנים |
| `src/index.html` | כל הטקסטים שמופיעים בסרטון |
| `src/main.js` | האנימציה של שמונה הסצנות |
| `src/guitar.js` | ציור הגיטרה |
| `src/style.css` | צבעים, פונטים ופריסה |
| `tools/audio.mjs` | מסנתז את הפסקול ל־`out/soundtrack.wav` |
| `tools/render.cjs` | מצלם כל פריים מהדפדפן ומחבר עם הפסקול ל־MP4 |
| `tools/still.cjs` | פריימים בודדים לבדיקה מהירה |

## הרצה

צריך Node 20 ומעלה, ffmpeg ו־Playwright עם Chromium (`npm i -D playwright && npx playwright install chromium`).

```bash
npm run preview   # תצוגה מקדימה חיה בדפדפן, עם סאונד וסרגל זמן
npm run render    # פסקול + רינדור מלא ל-tip-video.mp4 (כמה דקות)
node tools/still.cjs 2.5 12.6 33.8   # פריימים בודדים ל-out/stills/sheet.jpg
```

## שינויים נפוצים

- **טקסט:** עורכים ב־`src/index.html`. שורות הענק מתאימות את גודל האות לרוחב המסך בעצמן.
- **תזמון:** משנים את `SC` ב־`src/timing.js`. אחרי שינוי בתזמון או במוזיקה מריצים שוב `npm run audio`.
- **צבעים:** המשתנים בראש `src/style.css` (והאובייקט `C` בראש `src/main.js`).
- **התגית "טיפ למוזיקאים" למעלה:** ב־`#chrome` בתוך `src/index.html`. אפשר להחליף אותה בשם הערוץ.
